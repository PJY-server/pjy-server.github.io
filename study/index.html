API 키에 대해
AI-Hub에서 발급한 키는 현재 공식 안내상 aihubShell과 AI-Hub MCP에서 사용하는 키야. 일반 웹페이지가 직접 호출하는 문제 검색 REST API 키로 안내되어 있지 않아. 키가 채팅에 노출됐으니 AI-Hub에서 재발급하고, 새 키도 HTML/JavaScript에 붙여넣지 마.
AI-Hub 연동 관련 안내
공식 AI-Hub 오픈 API 키는 주로 데이터셋 조회·다운로드 도구(aihubShell/MCP)에 사용돼. 웹페이지에서 바로 수학 문제를 검색하는 일반적인 실시간 문제 API와는 달라. 데이터셋 이용 승인 및 실제 파일 형식 확인이 필요해.
AI-Hub에서 내려받은 문제 데이터(JSON 또는 CSV)가 있다면 아래에서 불러와 검색할 수 있어. 파일은 이 브라우저 안에서만 처리되며 서버로 업로드되지 않아.
